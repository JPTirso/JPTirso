# Sobre mim

> Me chamo João Pedro, tenho 17 anos e sou estudante de Desenvolvimento de Sistemas no Ensino Médio Técnico. Tenho interesse principalmente em desenvolvimento backend, arquitetura de software e, atualmente, venho direcionando meus estudos para a área de Cybersecurity, com foco futuro em Pentest.

> Tenho experiência prática desenvolvendo projetos com Node.js, Express, Prisma e PostgreSQL, buscando entender não apenas como implementar uma funcionalidade, mas também como estruturar APIs, lidar com autenticação, validação, permissões e regras de negócio. Atualmente, meu principal projeto em grupo é o **Notify**, uma aplicação de organização de estudos na qual sou responsável pelo desenvolvimento do backend.

> Meu objetivo é continuar construindo projetos que me obriguem a aprender na prática e aprofundar minha base em desenvolvimento de software, redes, sistemas e segurança. No longo prazo, quero utilizar essa base para atuar profissionalmente com Cybersecurity, especialmente na área de Pentest.
